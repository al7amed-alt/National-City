VELOCITY EXTREME V4 — IMMERSIVE ENVIRONMENT

V4 upgrades:
- Procedural engine/rev sound that responds to speed
- Wind noise that increases with speed
- Tire/steering sound
- More human-like 3D spectators with heads, torsos, arms, legs, varied skin tones and clothing
- Gradient sky dome
- Grass variation
- Red/white racing curbs
- Metal safety barriers
- Trackside trees and environmental detail
- Existing V3 garage, four car styles, AI racers, long circuit, lap/position/timing, cameras and controls retained

Run:
Open index.html in Chrome/Edge with internet access.
If local module security blocks loading:
python -m http.server 8000
then open http://localhost:8000

Audio begins only after START RACE is clicked, as required by modern browser audio security.

The environment is procedurally generated and more believable, but true AAA photorealism would require licensed high-poly models, PBR textures, animation rigs and recorded audio assets.
