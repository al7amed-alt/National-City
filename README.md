NATIONAL CITY PROTOTYPE v2

FILES INCLUDED
- index.html
- style.css
- game.js
- START_GAME.bat
- start_game.command

WINDOWS - SIMPLE METHOD
1. Extract the ZIP file.
2. Open the extracted folder.
3. Double-click index.html.

WINDOWS - LOCAL SERVER METHOD
1. Double-click START_GAME.bat.
2. A browser window should open automatically.
3. Keep the black command window open while playing.
4. Close the black window when finished.

MAC
1. Open Terminal.
2. Go to the extracted folder.
3. Run:
   python3 -m http.server 8000
4. Open:
   http://localhost:8000

CONTROLS
- Move: Arrow keys or W, A, S, D
- Interact: E
- Pause: P

GAMEPLAY
Choose a girl, boy, woman, or man.
A child plays as a student.
An adult plays as a community volunteer.
Walk to the building outlined in yellow and press E.


ON-SCREEN CONTROLS
- ▲ Move up
- ▼ Move down
- ◀ Move left
- ▶ Move right
- E / Interact: complete a mission near the highlighted building
- II / Pause: pause or resume the game

The on-screen controls work with a mouse, touchscreen, tablet, or phone.
Keyboard controls remain available.
